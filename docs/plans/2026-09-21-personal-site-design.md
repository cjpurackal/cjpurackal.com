# Personal site design

Approved direction: a minimal personal page centred on Christie's interest in mathematical foundations, geometry, algebra, and computer vision. Omit the proposed “Currently exploring” section.

Use one narrow column on a warm off-white background, readable serif typography, a short introduction, the approved generated pencil geometry study, and GitHub, email, and résumé links. Keep the artwork decorative; it is an evocative illustration rather than an exact mathematical diagram.

Retain a static HTML/CSS architecture. Remove Bootstrap and its JavaScript, use system fonts, and store the image locally. Use semantic markup, visible keyboard focus, wrapping links, and fluid image dimensions. Verify local assets and desktop/mobile layout where browser tooling is available.
